===========================================================
   Монте-Карло анализатор ГТУ (версия для Windows)
===========================================================

Программа выполняет вероятностный анализ газотурбинной установки
методом Монте-Карло (50 000 итераций). Результаты сохраняются в
виде Excel-отчёта со статистиками, гистограммой и торнадо-диаграммой.

=== Как запустить ==========================================

1. Распакуйте архив в любую папку (путь должен содержать только
   латинские буквы и цифры, без пробелов и кириллицы).

2. Откройте файл MonteCarlo.xlsm. Если Excel предупреждает о
   макросах – нажмите "Enable Content" ("Разрешить содержимое").

3. На листе "Config" заполните входные параметры начиная с 5-й строки
   (обязательно укажите хотя бы один параметр). Столбцы A–M соответствуют:
   - A: имя параметра (латиница)
   - B: тип распределения (только "triangular")
   - C: минимальное значение (min)
   - D: наиболее вероятное значение (mode)
   - E: максимальное значение (max)
   - F: базовое значение (ML)
   - G: шаг изменения (unit_step)
   - H..M: коэффициенты влияния на 6 выходов (порядок см. в примере)

   Все числа в столбцах C–M должны быть записаны с ТОЧКОЙ (например 0.63).

4. Используйте кнопки на листе:
   • «Запустить расчёт» – выполняет расчёт с параметрами из листа Config.
   • «Выбрать JSON» – позволяет запустить расчёт с любым JSON-конфигом.
   • «Открыть отчёт» – открывает последний сгенерированный отчёт.
   • «Очистить временные» – удаляет временный файл temp_config.json.

5. После нажатия «Запустить расчёт» Excel временно «зависнет» на время
   расчёта (обычно 10–30 секунд). После завершения автоматически
   откроется файл отчёта в формате .xlsx с листами:
   - Statistics (среднее, медиана, стандартное отклонение, процентили 5% и 85%)
   - Sensitivity_... (ранговые корреляции Спирмена)
   - Outputs_head (первые 1000 итераций)

   Также в папке появятся гистограмма и торнадо-диаграмма в формате PNG.

=== Математическая модель ==================================

Модель выполняет вероятностный анализ газотурбинной установки (ГТУ)
с учётом неопределённостей 19 входных параметров (компрессор, камера
сгорания, турбина, системы охлаждения). Связь между входами и выходами
линейна, с использованием псевдо-обменных коэффициентов (exchange rates),
полученных из нелинейных термодинамических расчётов.

1. Входные параметры

   Каждый вход i описывается треугольным распределением:
   - a_i = min, m_i = mode, b_i = max.
   Плотность вероятности:

        f_i(x) = { 2(x-a_i)/[(b_i-a_i)(m_i-a_i)] ,   a_i ≤ x ≤ m_i
                { 2(b_i-x)/[(b_i-a_i)(b_i-m_i)] ,   m_i ≤ x ≤ b_i

   - x_i^ML – базовое (most likely) значение (обычно равно mode).
   - δ_i – шаг изменения (единица, для которой задан коэффициент влияния).
   - c_{i,k} – коэффициент влияния на выходной параметр k при изменении
     входа x_i на один шаг δ_i.

2. Выходные параметры

   Каждый выход k имеет базовое значение y_k^ML (соответствует ситуации,
   когда все входы равны своим x_i^ML). При отклонении входов выход
   вычисляется по линейной формуле:

        y_k = y_k^ML + Σ_i ( (x_i - x_i^ML) / δ_i ) · c_{i,k}

   Используются 6 выходов:
   - GT Gross Power (MW)
   - GT Gross Efficiency (%)
   - CC Net Power (MW)
   - CC Net Efficiency (%)
   - Turbine exhaust temperature, TAT (K)
   - Exhaust mass flow (kg/s)

3. Симуляция Монте-Карло (N = 50 000 итераций)

   - Для каждого входа i генерируется N независимых случайных чисел x_i^{(j)}
     из треугольного распределения.
   - Для каждой итерации j рассчитываются выходы y_k^{(j)} по линейной формуле.
   - По полученным выборкам {y_k^{(j)}} вычисляются статистики:
        • среднее арифметическое
        • медиана (50% процентиль)
        • 5% и 85% процентили
        • стандартное отклонение

4. Анализ чувствительности

   Для каждой пары (вход i, выход k) вычисляется ранговая корреляция Спирмена
   по выборкам x_i^{(j)} и y_k^{(j)}. Это показывает, насколько сильно
   неопределённость входа влияет на разброс выхода. Результат выводится
   в виде торнадо-диаграммы для топ-10 наиболее влияющих входов.

5. Проверка модели (детерминированный тест)

   Установите один параметр с min = mode = max (константа) и любым
   ненулевым коэффициентом. Тогда при любом числе итераций выход должен
   быть строго равен y_k^ML. В отчёте должны получиться среднее = медиана =
   процентили = y_k^ML, стандартное отклонение = 0. Это служит проверкой
   корректности линейной модели.

=== Возможные проблемы и решения ============================

• Ошибка "Binary not found" – проверьте, что папка "bin" лежит рядом с
  MonteCarlo.xlsm и внутри есть mc_simulator.exe.

• Ошибка "Division by zero" – убедитесь, что в столбце G (UnitStep)
  все значения ненулевые и являются числами.

• Ошибка "Sheet 'Config' not found" – переименуйте лист в "Config"
  (латиница, с заглавной C).

• Если числа в Excel отображаются с запятой (например 0,63) – замените
  все запятые на точки (Ctrl+H, найти "," заменить ".").

• Если макросы не работают – включите их в настройках Excel:
  File → Options → Trust Center → Trust Center Settings → Macro Settings
  → Enable all macros.

• Если расчёт не открывает отчёт автоматически – нажмите кнопку
  «Открыть отчёт» вручную после завершения консоли.
